# Частина 5 — перерахунок лише з наданих даних

Статус: **повного економічного розв’язку немає, Cu/Co відсутні**. Не обчислюються цільовий сервіс, S, COEFF чи ORDER. Пропуски залишено порожніми; вони не означають нуль.

- [Висновок](../conclusions/запаси-сервіс-coeff.md)
- [Коротко для виступу](../conclusions/запаси-для-виступу.md)
- [Excel: дані та чого бракує](out/inventory_data_and_gaps.xlsx)
- [Перелік відсутніх параметрів](out/missing_inputs.csv)

Запуск із кореня репозиторію:

```powershell
python inventory/service_inventory.py
python -m inventory.test_service_inventory
```

Скрипт заново читає оригінальний Excel з `inputs/`, перевіряє його проти підготовленої бази й читає прогноз колеги. Параметри шляхів: `--source`, `--case`, `--out`. Звіт і короткий текст оновлюються у `conclusions/`; таблиці пишуться у вибрану папку виходу. Скрипт не читає старих сценарних параметрів і не має числових значень Cu/Co або заданого сервісу.

Що обчислюється: фактичні суми, добутки кількості на наданий прайс, кількість спостережень, описові ознаки перевірки, суми 3/4 повних місяців уже опублікованого прогнозу. Прогноз не змінюється й не продовжується за FY2025. Немає нового розподілу попиту, симуляції витрат, оптимізації запасу чи економічного бектесту на вигаданих ставках.

`observed_SKU.csv` містить первинні дані та порожні цільові поля. `calculation_status.csv` пояснює причини невизначеності. `summary.json` має `economic_results` зі значеннями null і статус `INCOMPLETE_MISSING_INPUTS`. `input_manifest.json` фіксує джерела. `validation.json` перевіряє арифметику й відсутність підставлених параметрів, а не завершеність економічної задачі.

Попередній код, ставки та сценарні результати відкликано й збережено лише в локальному ігнорованому архіві `.task_deps/retired_task5_with_assumptions/`. У поточних матеріалах та Git-пакеті їх немає. Інші частини колег збережено; старі сценарні демонстратори HTML/симуляції не є результатом цієї редакції частини 5.

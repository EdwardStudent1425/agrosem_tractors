# АГРОСЕМ — Трактори B

Командний аналіз кейсу АГРОСЕМ для групи B: запасні частини до тракторів.

## HTML-сторінки: почніть звідси

Папка [html/](html/) — зрозумілий огляд задачі, даних і розрахунків з інтерактивними інструментами. Стартова сторінка: [html/index.html](html/index.html).

**Як відкрити в браузері:**

- Двічі клікніть `html/index.html` у Провіднику — він відкриється у браузері за замовчуванням.
- Або з терміналу в корені репозиторію: `start html\index.html` (Windows) / `open html/index.html` (macOS) / `xdg-open html/index.html` (Linux).
- Сервер, інтернет і встановлення не потрібні. Не переміщуйте `index.html` окремо: папки `html/assets/` і `html/data/` мають лишатися поруч.

## Поточний стан

Підготовлено дані, аудит і сегментацію. Колеги додали перелік запитів на інформацію, аналіз сезонності та прогноз FY2025 із перевіркою на минулому. Частину 5 заново перераховано лише з наявних даних: описано фактичний стан і точно визначено прогалини. Повний економічний розв’язок неможливий: значення Cu/Co не надані. Цільовий сервіс, оптимальний запас, COEFF та нове замовлення залишено невизначеними.

У матеріалах описано:

- що маємо в даних і які первинні висновки отримали;
- наше розуміння проблеми: доступність запчастин за обмежених коштів на запаси;
- гіпотези вирішення: ощадливий, збалансований і сервісний сценарії;
- яких даних бракує та які обмеження мають запропоновані підходи.

Частина 5 не містить підставлених ставок витрат, вибраного рівня сервісу або розподілу попиту. Попередні сценарні результати цієї частини відкликано з активного пакета. Інші сценарні демонстратори колег збережені окремо; вони не є висновками нового перерахунку.

## Основні перевірені числа

- 13 398 SKU у групі «Трактори».
- 71 162 продані одиниці за листопад 2023 — жовтень 2024.
- 519 SKU із сумою місячних хітів рівно 3; це не доведена кількість унікальних клієнтів року.
- 67 948 пропусків у 36-місячній історії продажів збережено як невідомі значення.
- Неповний листопад 2024 відділено від повних місяців.

Зріз прийнято на 12.11.2024. Вартісні показники є оцінками за поточним прайсом: валюта й тип ціни не визначені. Service level і COEFF не прирівнюються один до одного.

## Відтворення

Python 3.11. Команди з кореня репозиторію:

```powershell
python -m pip install -r requirements-agrosem.txt
python build_agrosem_analysis.py --source 'inputs/12_11_2024_140029.xlsx' --case 'inputs/АГРОСЕМ_case.pdf' --output regenerated_results
python verify_agrosem_outputs.py --output regenerated_results --source 'inputs/12_11_2024_140029.xlsx'
python inventory/service_inventory.py
python -m inventory.test_service_inventory
```

Код і текстові шаблони підготовлено для наданого історичного зрізу. Для інших вхідних даних потрібно перевірити календар і адаптувати описові частини звітів. Первинні файли не змінюються.

`agrosem_results/validation_summary.json` містить 33 успішні перевірки готових файлів. У первинних даних залишаються три категорії питань REVIEW, описані в аудиті: невідомий CC 0, хіти за нульових продажів і неоднозначність доступного залишку відносно резерву.

Тимчасові файли, встановлені бібліотеки, кеші та дублікати коду для ZIP-пакета виключено через `.gitignore`.
